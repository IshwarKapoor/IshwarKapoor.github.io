# 🔋 Forecasting Lithium-Ion Battery Health Using NASA B0005 Data
*A hybrid technical–teaching guide to time-series forecasting and Remaining Useful Life prediction*

## Introduction

Lithium-ion batteries power everything—from electric vehicles and aircraft backup systems to laptops and smartphones. Over time, however, these batteries degrade as their usable capacity declines with each charge–discharge cycle. Being able to forecast battery degradation and estimate Remaining Useful Life (RUL) is crucial for safety, cost optimization, and energy management.

In this project, the **NASA B0005 battery dataset** is used to build machine learning models that:

1. Forecast future battery capacity  
2. Predict when the battery will hit its end-of-life threshold

The goal is to show a **complete, modern workflow** for engineering-oriented forecasting using a real-world dataset.

---

Battery health forecasting is a powerful application of machine learning in **materials science** and **energy engineering**. Using the NASA B0005 dataset, we demonstrated:

- How **capacity fades** in lithium-ion batteries  
- How to **forecast future degradation** using ML and LSTM  
- How to **predict Remaining Useful Life** using data-driven models  

This workflow can be adapted to **electric vehicle datasets**, **aerospace systems**, and real-world **battery diagnostics**.
